# Aacharya LMS

Aacharya is an Academic ERP, Interactive Learning Management System,
and Career Accelerator.

## Technology Stack

- Frontend: React, Vite, JavaScript, Tailwind CSS v3
- Backend: Node.js, Express.js, JavaScript
- Database: MongoDB and Mongoose
- Authentication: JWT access and refresh sessions
- Real-time communication: Socket.IO
- Testing: Automated frontend and backend tests
- Development: npm workspaces and Docker

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
- `docs/` — Product requirements, architecture, API contracts, and roadmap
